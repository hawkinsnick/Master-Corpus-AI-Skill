# Cross-Corpus Comparability Matrix — 1.0

This matrix governs *types* of comparison. It does not pre-authorize any substantive historical or linguistic conclusion.

| Question type | Default | Requirement to proceed |
|---|---|---|
| Repository/evidence coverage | ALLOWED | Define each corpus's native counting unit |
| Provenance/rights architecture | ALLOWED | Compare policies/fields, not rights grants |
| Sign/string frequency | GATED | Compatible sampling units, exclusions and representation layers |
| Positional/structural pattern | GATED | Compatible segmentation/unit definitions and declared null model |
| Palaeographic similarity | GATED | Source-quality images/observations and explicit feature method |
| Phonetic/sign-value equivalence | BLOCKED by default | Independent positive evidence beyond shape/interoperability |
| Lexical similarity | BLOCKED by default | Established readings plus method controlling chance/borrowing/dependence |
| Genetic language relationship | BLOCKED by default | Accepted linguistic evidence and comparative method |
| Decipherment transfer | BLOCKED | Independent decipherment evidence; values from another script are not sufficient |
| Chronological inference | GATED | Independently supported dating/provenance |
| Independent replication | GATED | Demonstrated source/witness/method independence |

When requirements are unmet, descriptive comparison remains permissible if limitations are explicit.
