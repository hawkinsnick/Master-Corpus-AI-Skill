# Start a research session

**Researcher guides:** [Step-by-step user guide](USER-GUIDE.md) · [Doctoral research examples for all 18 corpora](PHD-RESEARCH-EXAMPLES.md).

1. Start with [the canonical master instructions](SKILL.md) in this dedicated
   repository. Check [README.md](README.md) for scope and source boundaries.
2. Download [the starter text](downloads/Master-Corpus-AI-Skill-Starter.txt) and
   supply it to an AI assistant that can read uploaded text. Uploading gives the
   assistant context; it does not install a skill or grant access to corpus files.
3. Ask: “Use the master instructions. Confirm which files you can read. I am
   researching [question]. Select the relevant registered corpus, identify the
   evidence we need, and give one useful first lookup. Preserve unknowns.”
4. Use the [corpus directory](CORPUS-DOWNLOADS.md). Supply the selected member's
   individual skill, authority profile, bundle index, source/rights guides and
   exact evidence files, or provide permitted repository-file access.
5. Ask for the exact repository, collection, native ID, attribution, source locus,
   path/hash/pointer and limitations. Follow [the worked examples](WORKED-EXAMPLES.md).

For example, ask what the Linear A source record ARKH 1a reports. Its source
labels and metadata do not establish pronunciation, translation or physical
certification. Use the saved dossier only as an identified teaching snapshot,
or execute the native retrieval for current evidence.

For Python users, run `python scripts/validate.py` from this master checkout.
Native checkouts are additional inputs for `--checkouts` validation and query
commands. Missing source files or unexecuted checks must be disclosed.
